# Input examples

## replay.json

The 16 equally weighted complete matrices represent the clustered population exactly: each of the four s-survivor locations occurs three times with an all-zero r column and once with an all-one r column. Repetition represents probability mass, not additional independent observations for a confidence interval. The example computes the population cost comparison through an empirical-pool interface.

Scores, weights and bounds are dimensionless. Fractions are JSON strings for exact parsing. Startup and variable prices are service-cost units. Each matrix is `[entity][missing_role]`; rows preserve their slot identity. `known_contributions` is already weighted. All missing-role weights plus weights contributing to known terms should follow the paper's normalized aggregate convention.

The joint mean costs are 95/2 for r then s and 55 for s then r. The slot-product model instead chooses s first. Editing input matrices changes the estimates; no expected answer is printed in place of calculation. The loader checks complete shapes, score ranges and positive variable costs. Supply a scientifically admissible reference population as described in [the method guide](../docs/method.md).

## evidence.json

Four entities, two roles, k=1 and equal weights. Entity 3 has a missing role and is ineligible. Entities 0 and 1 tie at score 4/5, so entity 0 wins by ID. Entity 2 has low scores and extra passage records. Passage IDs are unique; duplicate-score representatives choose the smallest ID.

`groups` lists `{entity, role, passages}`, with each passage `[score_string, passage_id]`. The demo fills absent entity-role pairs with empty lists, constructs exact sorted streams, runs mixed access actions, and compares its certified result to exhaustive evaluation. The separate protocol checks include early stopping with resolved ties, retained unresolved equality, and discarded entities that remain unresolved at exhaustion.

[Computed demo output](demo-output.json) contains the estimates, selected orders, exact answer and action trace for these inputs. It is provided for browsing; `scripts/demo.py` recomputes it.

## embedding.json

This example supplies the global three-role state underlying the two-missing-role replay input. Its initialization scans the t stream and completes only the incumbent's r/s scores. The four candidates are then seen with both missing roles unobserved, known contribution 1/3 and local residual boundary 3/4. The selected concrete binary matrix is one supported clustered world. The example is browsable data; `src/check_embedding_region.py` constructs the same initialization for all binary worlds and checks certificate equivalence. It does not claim that every observation mask is generated by one fixed heuristic controller.
